# 👋 Introduction

Developers using the **Witnet SDK** packages will programmatically manage to:

:purse: _Create HD-wallets to hold and transact with $WIT coins._

:seedling: _Stake and withdraw $WIT coins into and from Witnet validators._

:abacus: _Build oracle queries adapted to all sorts of data sources and use cases._

:stethoscope: _Simulate resolution of oracle queries, locally and at no cost._

:judge: _Notarize resolution of oracle queries on the Witnet blockchain._

:newspaper: _Report resolution of oracle queries into smart contracts._

:chains: _Check dynamic information on the Witnet P2P network._

:mag\_right: _Explore public data on the Witnet blockchain._

:identification\_card: _Generate legit stake-authorization codes for external customers._
